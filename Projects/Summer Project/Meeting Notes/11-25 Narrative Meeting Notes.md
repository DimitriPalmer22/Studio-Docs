# Supplementary Dialogue

### Post-Reading Dialogue
- Maybe it isn't the best to throw the player into dialogue after reading a journal entry (especially if we're just going over what was in the entry)
- Instead, we could incorporate the dialogue into the journal note UI
- Additionally, we could reduce the post-reading dialogue to be one-liners that are short little quips for what has been written.
- We can keep these responses generic and select them from a pool. For more unique ones, we can have unique dialogue.
