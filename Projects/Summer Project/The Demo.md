# What Is In The Demo

## Deadline for Content Submission

Our deadline for content that needs to be within the Demo is *January 18th*. This way, we have time to review and make any necessary adjustments before the final submission.

## The Demo is a Tailored Experience

### No Unfinished / Unpolished Content!
Players will only see what we choose to show them. If something is not ready, it simply won't be included in the Demo. We will shape the demo around the content that is ready and polished.

### Players will Play the Exact Same Run Over and Over!
Our game is a roguelite experience, with procedurally generated elements. However, for the Demo, we will create a fixed experience that all players will go through. This allows us to control the narrative and gameplay experience more tightly.

Every single time the player starts a new run in the demo, we will treat it as if they are playing the game for the first time. Therefore, the player will have no saved progress, and will always start from the same point with the same initial conditions.
